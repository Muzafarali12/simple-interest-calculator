# Simple Interest Calculator

A simple, beginner-friendly calculator that computes **Simple Interest** based on Principal amount, Rate of interest, and Time period.

## 📌 Description

This project calculates the simple interest on a given principal amount using the standard formula. It is designed as a small learning project to demonstrate basic input handling, arithmetic operations, and output formatting.

## 🧮 Formula Used

Simple Interest is calculated using the formula:

```
SI = (P × R × T) / 100
```

Where:
- **P** = Principal amount (the initial sum of money)
- **R** = Rate of interest per annum (in %)
- **T** = Time period (in years)
- **SI** = Simple Interest earned/payable

The **Total Amount** after interest is:

```
A = P + SI
```

## ✨ Features

- Takes Principal, Rate, and Time as input
- Calculates Simple Interest instantly
- Displays the Total Amount (Principal + Interest)
- Clean, easy-to-understand logic suitable for beginners
- Input validation to avoid negative or invalid values

## 🛠️ How It Works

1. The user enters the **Principal amount** (P).
2. The user enters the **Rate of interest** (R) in percentage.
3. The user enters the **Time period** (T) in years.
4. The program applies the formula `SI = (P × R × T) / 100`.
5. The calculated **Simple Interest** and **Total Amount** are displayed to the user.

## 📥 Example

| Input | Value |
|-------|-------|
| Principal (P) | 10000 |
| Rate (R) | 5% |
| Time (T) | 2 years |

**Calculation:**
```
SI = (10000 × 5 × 2) / 100 = 1000
Total Amount = 10000 + 1000 = 11000
```

**Output:**
```
Simple Interest = 1000
Total Amount = 11000
```
